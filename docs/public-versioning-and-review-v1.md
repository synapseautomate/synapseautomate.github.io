# Public Versioning & Review Policy v1

Canonical public policy: https://synapseautomate.github.io/guven/versiyonlama-inceleme-politikasi.html

## Required fields
- version
- updated date
- review due date
- owner
- review mode
- external expert review flag
- status / deprecation behavior

## Claim boundary
Internal editorial review is **not** external expert review. “Expert-reviewed” or equivalent wording may be used only when a real reviewer has inspected the named artifact and public attribution is permitted.

## Freshness behavior
A current asset whose review due date has passed must move to review-required, be re-validated, or be deprecated/redirected.
