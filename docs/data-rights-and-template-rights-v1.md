# Data Rights & Reusable Template Rights v1

This public repository separates reusable delivery IP from customer-specific data and confidential configuration.

## Public-safe reusable layer
- workflow schemas and state models
- acceptance-test structure
- human approval / stop boundaries
- incident escalation structure
- monitoring signal contracts

## Never placed in the public template library
- customer records or customer-identifiable data
- credentials, API keys or production access data
- confidential customer documents or contracts
- undisclosed customer thresholds, pricing or business rules
- real customer cases unless separately permissioned and intentionally published

## Rights metadata
Every public reusable asset should have a source, version, right, expiry/review status and customer scope. Unknown rights are treated as a stop condition, not as permission.

## Paid delivery boundary
The exact ownership/licensing split for customer inputs, project-specific deliverables and reusable generic components is defined in the written offer or contract. This document is a public methodology note, not legal advice or a contract.
