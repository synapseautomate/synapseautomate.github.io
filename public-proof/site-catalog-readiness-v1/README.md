# Site & Katalog AI Hazırlık - public proof v1

Bu paket Synapse Automate ücretsiz hazırlık taramasının sentetik/deterministik kanıt yüzeyidir.

- 7 kategori rubric
- kaynaklı küçük context_store_v1
- yanlış/eski/çelişkili context retrieval testleri
- 20 sentetik adversarial vaka
- veri akışı ve hash tabanlı audit log örneği
- yetkili silme testi
- yanlış pozitif revizyon notu

## Sınırlar
Bu paket gerçek müşteri verisi içermez. Production accuracy, güvenlik sertifikası, AI görünürlük/sıralama veya ticari sonuç garantisi değildir.
