# Comparison Performance Report v1

## Reality status
- Real comparison tests completed: 0/5 unless updated from actual inbound.
- Qualified inbound: 0 unless a verified event exists.
- Paid conversion: 0 unless a verified payment exists.

## Required fields for each real test
Baseline cycle time, 3 redacted cases, system result, source/provenance, human correction minutes, error category, trust boundary, next step/date.

## Decision rule
Do not treat praise as a metric. Record booked / accepted / paid separately.
