# Partner Delivery One-Pager

## White-label scope
A partner can present Synapse Automate's workflow analysis and pilot design under the partner's client-facing brand, while the underlying delivery remains bounded by the same evidence, human-approval and data-minimization rules.

### Included
- One workflow discovery / process map
- Source and data-scope definition
- Human-approval / authority boundaries
- Synthetic test set and acceptance criteria
- Pilot design and measurement plan
- Handoff package for the partner

### Not included by default
- Autonomous payment, pricing, contracting or external-write authority
- Legal/compliance certification
- Guaranteed ROI or conversion uplift
- Raw client data transfer across partner/client boundaries without explicit permission

### Commercial structure
Start with **Süreç Analizi: 4.900 TL / $149**. If the workflow is suitable, define a separate pilot scope. Partner margin, invoicing and tax treatment require explicit commercial agreement; none are assumed here.
